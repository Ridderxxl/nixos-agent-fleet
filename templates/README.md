# Templates for a separate private fleet repository

These are text starting points, not the original operator's configuration. They do not create hosts, users, permissions or services.

- [AGENTS.md](AGENTS.md): short private-project operating contract; replace explicit TODOs with verified paths and checks.
- [handoff.md](handoff.md): bounded task/session handoff.
- [decision.md](decision.md): architecture decision record.
- [acceptance.md](acceptance.md): evidence-oriented deployment acceptance.

Copy only selected files to your own private implementation. Do not treat unknown hostnames, commands, recovery procedures or approvals as filled in. Keep private task state and real observations out of this public repository.
